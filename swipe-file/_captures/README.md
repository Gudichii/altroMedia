## Kako skinuti

**Full-page screenshot (Chrome, bez ekstenzije):**
F12 → Ctrl+Shift+P → utipkaj "Capture full size screenshot"

**Cijela stranica kao jedan HTML:**
Chrome ekstenzija **SingleFile** — spremi sve u jedan .html s ugrađenim slikama

**Aktivni oglasi:**
facebook.com/ads/library → Search by advertiser → ime brenda
Oglas koji vrti 6+ mjeseci = pobjednik. Screenshotaj ga.

**Stare verzije funnela (2015-danas):**
`web.archive.org/web/2016*/dotcomsecrets.com`
Usporedi 2016 vs 2020 vs danas — ono što su zadržali je pobjednik.
