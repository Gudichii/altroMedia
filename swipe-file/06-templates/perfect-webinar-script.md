# PERFECT WEBINAR — puna skripta (hrvatski)

Brunsonov format, preveden i prilagođen. Trajanje: 60–90 min.
Popuni zagrade i imaš webinar.

---

## Prije pisanja — definiraj 4 stvari

```
JEDNA STVAR koju prodajem:     _______________________
  (jedan proizvod, jedna cijena, jedan rezultat)

TRI LAŽNA UVJERENJA koja ih koče:
  1. O VOZILU (metodi):    "________ ne radi / nije za mene"
  2. O SEBI:               "Ja ne mogu jer ________"
  3. O VANJSKOM:           "Nemam ________ (vrijeme/novac/publiku)"

NASLOV: Kako [rezultat] ... bez [strah]
  → _______________________________________
```

## DIO 1 — INTRO (15–20 min)

### 1.1 Hook (0:00–2:00)
```
"U sljedećih [60] minuta pokazat ću ti točno kako [REZULTAT],
čak i ako [NAJVEĆA OBJEKCIJA].

Ostani do kraja jer na kraju ću ti pokazati [KONKRETNA STVAR
KOJU DOBIJU BESPLATNO SAMO AKO OSTANU]."
```

⚠️ Otvoreni loop na početku podiže zadržavanje za 20-30%.

### 1.2 Tko si i zašto slušati (2:00–5:00)
Kratko. Ne CV. **Rezultati + jedan neuspjeh.**
```
"Zadnjih [X] godina radim [ŠTO]. Napravio sam [KONKRETAN REZULTAT].
Ali prije toga sam [NEUSPJEH], i to me naučilo [POUKA]."
```

### 1.3 Origin story / Epiphany Bridge (5:00–18:00)
Ovo je **najduži i najvažniji dio uvoda.**
```
1. BACKSTORY   — gdje sam bio
2. ŽELJA       — što sam htio (vanjski + unutarnji motiv)
3. ZID         — što me zaustavilo
4. EPIPHANY    — trenutak uvida
5. PLAN        — što sam napravio
6. KONFLIKT    — što je pošlo po zlu
7. POSTIGNUĆE  — rezultat
```

**Ovdje predstavljaš NOVU PRILIKU, ne poboljšanje:**
```
"To što ću ti pokazati nije [POSTOJEĆA KATEGORIJA] samo bolji.
To je potpuno drugačiji pristup. Zovem ga [IME MEHANIZMA]."
```

## DIO 2 — SADRŽAJ: 3 TAJNE (30–40 min)

Struktura je identična za sve tri:
```
a) Imenuj lažno uvjerenje
b) Ispričaj priču koja ga ruši (tvoju ili klijentovu)
c) Daj konkretan, upotrebljiv uvid
d) Most na sljedeće
```

### TAJNA #1 — ruši uvjerenje o VOZILU (10–13 min)
> Lažno uvjerenje: *"Digitalni proizvodi ne rade u mojoj niši /
> hrvatsko tržište je premalo"*

```
"Tajna #1: [NASLOV]

Znam što misliš — [LAŽNO UVJERENJE]. I mislio sam isto.
Dok nisam vidio [PRIČA / KLIJENT].

[KONKRETAN UVID KOJI MOGU ODMAH KORISTITI]

Ali čak i kad shvatiš ovo, javi se sljedeće pitanje..."
```

### TAJNA #2 — ruši uvjerenje o SEBI (10–13 min)
> Lažno uvjerenje: *"Ja to ne mogu — nisam tehnički, nemam dovoljno pratitelja,
> ne znam snimati"*

```
"Tajna #2: [NASLOV]

Najveća zabluda je da za ovo trebaš [ŠTO MISLE DA TREBAJU].
[KLIJENT] je imao samo [MALO RESURSA] i napravio [REZULTAT].

[UVID]

Ali onda dolazi zadnja prepreka..."
```

### TAJNA #3 — ruši VANJSKO uvjerenje (10–13 min)
> Lažno uvjerenje: *"Nemam vremena / novca / pravi trenutak"*

```
"Tajna #3: [NASLOV]

[PRIČA]
[UVID]

I tu dolazimo do pitanja koje mi svi postave..."
```

## DIO 3 — PRIJELAZ NA PRODAJU (2 min)

**Kritični trenutak.** Ako je nespretan, gubiš pola publike.
```
"Dopusti mi jedno pitanje.

Ako bih ti mogao pokazati kako [REZULTAT], i ako bi to zaista
funkcioniralo — bi li ti to vrijedilo [X] minuta pažnje?

Jer sve što sam ti pokazao su tri komada slagalice.
Sad ću ti pokazati cijelu sliku."
```

Nikad ne skreći naglo iz vrijednosti u prodaju. **Traži dopuštenje.**

## DIO 4 — THE STACK (15–20 min)

Ovo je Brunsonov potpis. Nabrajaš element po element,
**i nakon svakog ponoviš CIJELI stack.**

```
"Dobivaš [ELEMENT 1] — vrijednost [X]€"
   → prikaži: Element 1 = X€ | UKUPNO: X€

"Plus [ELEMENT 2] — vrijednost [Y]€"
   → prikaži: Element 1 = X€, Element 2 = Y€ | UKUPNO: X+Y€

"Plus [ELEMENT 3] — vrijednost [Z]€"
   → prikaži sve tri | UKUPNO: X+Y+Z€

... i tako do kraja
```

**Zašto ponavljanje cijelog stacka:** svaki put kad ga vide,
ukupan broj raste. Do zadnjeg elementa broj je toliko velik
da cijena izgleda apsurdno niska. To je cijeli trik.

### Otkrivanje cijene
```
"Ukupna vrijednost: [UKUPNO]€

Da si me angažirao direktno, ovo bi bilo [3× CIJENA]€.

Ali ne plaćaš ni [2× CIJENA]€.
Ni [1.5× CIJENA]€.

Danas ulaziš za [CIJENA]€."
```

### Garancija
```
"I evo zašto nemaš što izgubiti:
[GARANCIJA — vidi 02-alex-hormozi/swipe-copy.md sekcija 4]"
```

### Hitnost (mora biti stvarna)
```
"Ovo vrijedi [SAT/DO DATUMA] jer [STVARAN RAZLOG].
[BROJ] mjesta, jer [STVARAN RAZLOG ZAŠTO OGRANIČENJE]."
```

⚠️ Ako nemaš stvaran razlog za ograničenje — **izmisli stvaran razlog,
ne lažni.** Primjer stvarnog: "primam 3 klijenta mjesečno jer svaki build
traje 20 sati mog vremena." To je istina i provjerljivo.
