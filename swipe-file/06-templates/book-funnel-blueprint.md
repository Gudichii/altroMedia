# BOOK / LEAD MAGNET FUNNEL — blueprint

Brunsonov Free+Shipping skelet, prilagođen za digitalni proizvod na Balkanu
(fizička knjiga s poštarinom je u HR logistički problem, digitalni ekvivalent nije).

---

## Skelet

```
[1] SALES PAGE
      ↓
[2] ORDER FORM (2-step) + ORDER BUMP
      ↓
[3] OTO 1  ──ne──→ [4] DOWNSELL 1
      ↓                    ↓
[5] OTO 2  ──ne──→ [6] DOWNSELL 2
      ↓                    ↓
[7] THANK YOU PAGE
```

---

## [1] Sales page — struktura odozgo prema dolje

```
┌─ HEADLINE (formula: "bez")
├─ SUBHEADLINE (kome + vremenski okvir)
├─ VIZUAL (3D mockup proizvoda, velik, iznad prijeloma)
├─ VIDEO (2-4 min, ti govoriš u kameru, držiš proizvod)
├─ CTA GUMB #1  ← već ovdje, iznad prijeloma
├─ "Ovo je za tebe ako..." (3-5 prozivki)
├─ ŠTO DOBIVAŠ (8-12 bulleta, svaki = curiosity gap)
├─ CTA GUMB #2
├─ TKO SAM JA (kratko, rezultati + jedan neuspjeh)
├─ SOCIAL PROOF (3-5 testimoniala, po mogućnosti video)
├─ VALUE STACK (nabroji + zbroji + otkrij cijenu)
├─ GARANCIJA (u okviru, vizualno istaknuta)
├─ FAQ (5-7 pitanja = 5-7 objekcija)
└─ CTA GUMB #3
```

**Bulleti — formula za curiosity gap:**
```
❌ "Poglavlje o cijenama"
✅ "Zašto cijena od 97€ prodaje bolje od 47€ (str. 34)"

❌ "Kako napraviti landing page"
✅ "Jedna rečenica na vrhu stranice koja je udvostručila prodaju klijentu (str. 12)"
```

Bullet mora obećati **specifičan uvid**, ne opisati sadržaj.

## [2] Order form — 2-step

**Korak 1:** samo ime + email → gumb "Nastavi"
**Korak 2:** podaci za plaćanje

**Zašto 2 koraka:** uhvatiš email prije nego odustane na kartici.
Tko odustane u koraku 2 → ulazi u cart abandonment sekvencu.
To je 10-20% dodatnog prihoda iz ljudi koje bi inače izgubio.

### Order bump

```
┌────────────────────────────────────────────────┐
│ ☐  DA! Dodaj mi [BONUS] za samo +[X]€          │
│                                                 │
│    [Jedna rečenica zašto mu treba baš sad]     │
└────────────────────────────────────────────────┘
```

**Pravila order bumpa:**
- Cijena: **25–50% cijene glavnog proizvoda**
- Mora biti **komplementaran**, ne alternativa
- Checkbox mora biti vizualno istaknut (okvir, druga boja pozadine)
- Copy u prvom licu ("DA! Dodaj mi...")

**Očekuj 20–40% prihvaćanja.** Ovo je najlakši novac u cijelom funnelu.

**Primjeri za tvoje klijente:**
| Glavni proizvod | Order bump |
|-----------------|------------|
| Online program 97€ | Tjedni jelovnici u PDF-u, +27€ |
| Tečaj 197€ | Snimke svih live Q&A sesija, +47€ |
| Blueprint 37€ | Popunjeni primjeri + template, +17€ |

## [3] [5] OTO stranice

```
┌─ "ČEKAJ — narudžba još nije gotova"
├─ Video (60-120 sek, ti, direktno)
├─ Jedna ponuda, jedna cijena
├─ Zašto SAMO SAD (jednokratna prilika)
├─ [ VELIKI GUMB DA ]
└─ [ mali sivi link ne ]
```

**Pravila:**
- **Nema navigacije.** Nema menija, nema logotipa koji vodi natrag.
- **One-click upsell** — kartica je već unesena, ne traži je ponovno.
  Ovo udvostručuje konverziju upsella.
- "Ne" link mora imati **bolnu alternativu**:
  > "Ne, hvala — radije ću sam pokušavati mjesecima"

---

## [4] [6] Downsell stranice

Gadzhijeva logika: **ne puštaj "ne" van iz funnela.**

Tri načina downsella:
1. **Rate plan** — isto, 3 rate umjesto jednokratno
2. **Okrnjena verzija** — manje sadržaja, niža cijena
3. **Kraći period** — 1 mjesec umjesto 6

**Formulacija koja čuva vrijednost:**
```
❌ "Ok, evo ti 50% popusta"          (ruši percipiranu vrijednost)
✅ "Razumijem. Evo verzije koja ti odgovara za početak."   (mijenja ponudu, ne cijenu)
```

---

## [7] Thank you page

**Ne piše samo "hvala".** Ovo je najvrjednija stranica u funnelu
jer je kupac u najvišoj točki entuzijazma.

```
┌─ "Gotovo! Evo što sad."
├─ KORAK 1: Provjeri email (postavlja očekivanje, smanjuje support)
├─ KORAK 2: Uđi u grupu / zajednicu  ← retention
├─ KORAK 3: [Sljedeća ponuda ili booking poziva]
└─ (opcionalno) "Poznaješ nekoga kome ovo treba? Pošalji mu link" ← referral
```

## Realna računica za hrvatsko tržište

```
Front-end:      37€
Order bump:     17€  (30% uzme)  = +5.10€ po kupcu
OTO 1:         147€  (12% uzme)  = +17.64€ po kupcu
Downsell 1:     67€  (8% uzme)   = +5.36€ po kupcu
──────────────────────────────────────────────────
AOV:                              ~65€ po kupcu

Konverzija sales pagea: 3% (topao promet)
1.000 posjetitelja → 30 kupaca × 65€ = 1.950€
EPC = 1.95€

Ako je CPC 0.30€ → ROAS 6.5×. Skalabilno.
Bez bumpa i upsella: EPC = 1.11€, ROAS 3.7×. I dalje ok, ali 43% slabije.
```

**To je razlog zašto Brunson nikad ne prodaje samo jednu stvar.**
Ista publika, isti promet, isti trošak — 43% više prihoda.
