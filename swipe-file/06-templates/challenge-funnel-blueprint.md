# CHALLENGE FUNNEL — blueprint

Brunsonov OFA model, prilagođen. Najbolji format kad prodaješ **transformaciju**
koja traži da kupac nešto **napravi**, ne samo nauči.

---

## Zašto challenge tuče webinar i tečaj

| | Tečaj | Webinar | **Challenge** |
|---|-------|---------|---------------|
| Angažman | 5-15% završi | 1 sat jednom | **40-60% završi** |
| Gradi naviku | ne | ne | **da** |
| Gradi identitet | ne | ne | **da** |
| Refund rate | visok | — | nizak |

**Ključ:** netko tko je 7 dana radio tvoje zadatke više nije
"zainteresiran za temu". On je **već postao osoba koja to radi.**
Prodaja na kraju je samo potvrda identiteta koji je već usvojio.

---

## Skelet

```
[1] Sales page (challenge, 5-30 dana, 27-100€)
      ↓
[2] Order form + ORDER BUMP
      ↓
[3] VIP UPSELL (+ ista cijena kao challenge)
      ↓
[4] Zajednica (WhatsApp / Skool / FB grupa)
      ↓
[5] CHALLENGE (dnevni zadatak + dnevni video)
      ↓
[6] Zadnji dan = PITCH glavne ponude
```

---

## [1] Sales page

Ista struktura kao book funnel, ali s dvije dodatne komponente:

**Dnevni raspored — pokaži ga cijelog.**
```
DAN 1: [Naslov] → izlaziš s: [konkretan output]
DAN 2: [Naslov] → izlaziš s: [output]
DAN 3: [Naslov] → izlaziš s: [output]
...
DAN 7: [Naslov] → izlaziš s: [output]
```

**Zašto:** kupac vidi točno u što ulazi. Nema misterije,
nema straha od "još jednog tečaja koji neću završiti".
Svaki dan ima **opipljiv output**, ne "naučit ćeš".

**Datum početka.** Challenge ima **kohortu**, ne evergreen pristup.
```
"Kreće u ponedjeljak, [DATUM]. Prijave zatvaram u nedjelju u 20h."
```
Stvarna hitnost bez izmišljanja.

## [3] VIP upgrade — najlakše udvostručenje AOV-a

**Brunsonov OFA:** $100 challenge + **$100 VIP**.
Cijena VIP-a = cijena osnovnog proizvoda. Uzima ga 30-40%.

**Što ide u VIP (a ne košta te puno):**
```
✓ Dnevni live Q&A (30 min, pon-pet)  ← jedini pravi trošak vremena
✓ Privatna VIP grupa
✓ Pregled tvog rada (async, snimiš Loom od 5 min)
✓ Snimke svih sesija (trajni pristup)
✓ Bonus templatei
```

**Računica:**
```
100 sudionika × 47€           = 4.700€
35 uzme VIP × 47€             = 1.645€
──────────────────────────────────────
                                6.345€  (+35% bez novog prometa)
```

## [5] Dnevna struktura challengea

Svaki dan, isti format:
```
06:00  Email + poruka u grupi: "Dan X je live"
       ↓
       Video (10-20 min): sadržaj dana
       ↓
       ZADATAK (konkretan, izvediv u 30-60 min)
       ↓
       "Objavi svoj rezultat u grupi"  ← accountability
       ↓
20:00  Live Q&A (VIP) / snimka odgovora (svi)
```

**Nedjeljivo pravilo:** svaki dan mora imati **jedan konkretan output.**
Ne "razmisli o svojoj niši" — nego "napiši 3 rečenice u ovaj template i objavi ih".

---

## [6] Pitch zadnjeg dana

Ne prodavaj prvog dana. Ne prodavaj u sredini. **Zadnji dan.**

```
1. REKAPITULACIJA — "u 7 dana si napravio [nabroji sve outpute]"
   → kupac vidi koliko je napravio → osjeća kompetenciju
2. SLJEDEĆI PROBLEM — "sad imaš X, ali ti treba Y da to zaživi"
3. PONUDA — [tvoj DWY build / viši tečaj]
4. STACK + garancija + rok
5. "Tri tipa ljudi" close
```

**PSP logika ponovno:** challenge riješi jedan problem i time otkrije sljedeći.

## 🇭🇷 Konkretna primjena — 7-dnevni challenge za tvoje klijente

**Za trenera/nutricionista kojem gradiš proizvod, challenge je odličan
prvi digitalni proizvod** jer:
- Ne traži snimanje 40 sati sadržaja (7 kratkih videa)
- Prodaje se lakše od tečaja (niži rizik, jasniji rok)
- Gradi zajednicu koja kupuje sljedeći proizvod

```
"7 dana bez šećera" / "7 dana mobilnosti" / "7 dana meal prepa"
Cijena: 27–47€
VIP: +27–47€ (dnevni live + pregled)
Backend: veliki program 197–297€
```

Ovo je proizvod koji možeš isporučiti klijentu unutar svojih 30 dana,
i koji mu odmah donese prvih 10 prodaja — točno ono što obećavaš
u pozicioniranju.

**Za tebe samog — "5 dana do prve online ponude":**
```
Dan 1: Definiraj kome točno prodaješ
Dan 2: Napiši ponudu (template)
Dan 3: Odredi cijenu (kalkulator)
Dan 4: Napiši sales copy (framework)
Dan 5: Postavi checkout (screen recording, korak po korak)

Cijena: 47€ | VIP: +47€
Backend: DWY build 1.500€
```
